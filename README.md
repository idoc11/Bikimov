# Шторм

Аркада на выживание: ночная вахта в штормовом море. Небольшое судно с прожектором,
из темноты всплывают морские твари; цель — продержаться восемь минут и закрыть Око шторма.
Без зависимостей — просто открой `index.html`.

- **WASD** — ход, **мышь** — прожектор и прицел (огонь автоматический)
- **Пробел** — рывок, **Q** — способность судна, **P** — пауза, **M** — звук
- На телефоне: стик слева, тап справа — рывок, кнопка в углу — способность, прицел сам
- Геймпад: левый стик — ход, правый — прицел, A — рывок, X — способность, Start — пауза

Пять судов со своими способностями, 17 улучшений с эволюциями, трофеи с боссов,
три сложности, режимы «Классика» и «Босс-раш», испытания, задания дня, достижения
и док с постоянными улучшениями за жетоны.

## Как это нарисовано

Вся графика процедурная, картинок в репозитории нет.

- **Вода** — фрагментный шейдер WebGL: волны, пена, блики прожектора и вспышек.
  Без WebGL игра работает на ровном фоне.
- **Свет** — отдельный слой ночи, в котором прожектор, выстрелы и молнии «прожигают» дыры.
- **Спрайты** рисуются кодом заново под каждый угол поворота, чтобы свет всегда падал с одной стороны.
- **Интерфейс** — антиква Oranienbaum в заголовках, Golos Text в тексте, JetBrains Mono в цифрах.

## Отдельная программа для Windows

`dist/Shtorm.exe` — игра одним файлом, установка не нужна. Внутри вшиты сама игра и шрифты,
интернет не требуется. Программа открывает игру в отдельном окне через Edge или Chrome
(Edge есть в любой Windows 10/11); если их нет — во вкладке браузера по умолчанию.

Пересобрать после изменений в `index.html` (нужен только Go): `launcher/build.sh`.

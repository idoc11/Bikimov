# ШТОРМ

Браузерный аркадный шутер на выживание. Без зависимостей — просто открой `index.html`.

- **WASD** — движение, **мышь** — прицел (огонь автоматический)
- **Пробел** — рывок, **Q** — ударная волна, **P** — пауза, **M** — звук
- На телефоне: стик слева, тап справа — рывок, кнопка в углу — ударная волна, автоприцел

Пять кораблей, 17 улучшений с эволюциями на максимуме, переброс (R), реликвии с боссов, три сложности, бонусы с врагов, комбо и очки,
три типа боссов, случайные события (орда, метеоритный дождь, двойной опыт), музыка,
достижения и ангар с постоянными улучшениями за кредиты. Цель забега — дожить до 8:00
и уничтожить Ядро шторма; после победы можно продолжить в бесконечном режиме.

Геймпад: левый стик — движение, правый — прицел (без него автоприцел), A — рывок,
X — ударная волна, Start — пауза; на экране улучшений X / Y / B выбирают карточку, LB — переброс.

Испытания в меню (Рой, Хрупкость, Без рывка, Туман) усложняют забег и увеличивают награду в кредитах.
